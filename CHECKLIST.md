## Common Issues Checklist

### If app won't run:
- [ ] Did you run `flutter pub get`?
- [ ] Is Chrome browser installed?
- [ ] Did you run `flutter config --enable-web` (if needed)?
- [ ] Are you in the correct directory?

### If Git push fails:
- [ ] Did you create the GitHub repository first?
- [ ] Is the remote URL correct? (`git remote -v`)
- [ ] Are you logged into GitHub?
- [ ] Did you initialize Git? (`git init`)

### If screenshots are incomplete:
- [ ] Can you see the terminal commands clearly?
- [ ] Is the browser window visible?
- [ ] Is the VS Code Explorer expanded?
- [ ] Can the instructor read the text?
